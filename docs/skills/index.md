## Install and author

- [Installation guide](https://github.com/hmzainjamil/claude-skills/blob/main/INSTALLATION.md) explains the host installers and filesystem changes.
- [Authoring standard](https://github.com/hmzainjamil/claude-skills/blob/main/SKILL-AUTHORING-STANDARD.md) defines the skill file format.
- [Repository conventions](https://github.com/hmzainjamil/claude-skills/blob/main/CONVENTIONS.md) covers structure and contribution rules.

The repository's indexes and documents list different skill totals. No unique-skill total is published here because host exports may duplicate source entries.
